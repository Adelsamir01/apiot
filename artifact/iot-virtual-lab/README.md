# IoT Virtual Lab configuration (bundled)

This directory contains the **IoT Virtual Lab** configuration materials referenced by the paper’s artifact release: device library configs, lab API/orchestration scripts, impairment helpers, and integration docs.

Full firmware images and the complete lab repository remain at:

https://github.com/Adelsamir01/iot_vlab

Large binary images (initrd, firmware blobs) are intentionally not duplicated here.
