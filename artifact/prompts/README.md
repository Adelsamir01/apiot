# Prompt definitions

These files are extracted from `core/agent.py` for convenient inspection.

| File | Paper term | Source symbol |
|---|---|---|
| `guided_system_prompt.txt` | Guided prompt | `SYSTEM_PROMPT` |
| `blind_system_prompt.txt` | Blind prompt | `BLIND_SYSTEM_PROMPT` |

Blind mode is enabled by setting environment variable `APIOT_BLIND_MODE=1` (see `scripts/run_experiment.py`).
