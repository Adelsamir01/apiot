# APIOT

**Autonomous Purple-teaming for Industrial OT**

Research artifact accompanying the manuscript submitted to *Computers & Security*.

## Artifact contents

The paper’s artifact release is organised under [`artifact/`](artifact/README.md):

- APIOT source (`core/`, `toolkit/`, `scripts/`, `tests/`)
- IoT Virtual Lab configuration (`artifact/iot-virtual-lab/`)
- Prompt definitions (`artifact/prompts/`)
- JSON tool schemas — 21 tools (`artifact/schemas/`)
- Analysis scripts (`scripts/analysis/`)
- Sanitized run summaries with token-use logs (`artifact/sanitized-runs/`)
